# 課程通知訂閱｜2026-10-25

使用者已核可：驗證信箱後訂閱、只通知已公告課程、每封課程通知可退訂。目前沒有開放課程；預約時段、改期與取消規則只先擬建議，未開放時段或正式報名。

## 對外流程

- 企業學院原 `#public` 區域提供獨立訂閱表單，不把既有洽詢者加入通知。
- 訂閱、驗證及停止操作使用獨立 n8n API：`https://hansondm.app.n8n.cloud/webhook/hanson-website-participation-v1`。GET `/catalogue`、GET `/receipt`、POST `/action`；不是原 v3 洽詢端點。
- 只有驗證信箱才加入名單。沒有課程時，只寄驗證及訂閱確認等交易信，不寄開課通知。
- 驗證與停止連結放在 `/contact/#participation/<action>/<token>`，不含信箱。開頁或 GET 不異動，必須按對應按鈕；已用、逾期及操作不符的連結拒絕。
- 資料用途為 `/privacy/#participation`，獨立版本 `2026-10-25-participation-v1`；原洽詢告知仍為 `2026-10-24-v3`，privacy 保持 noindex,nofollow。
- 新公開 API 旗標由 n8n 管理，網址存在或網站建置成功不等於啟用。

## 私有處理

n8n 專用 Data Table 保存私有訂閱狀態、UUID、同意、驗證及停止狀態、寄信意向與防重；Smartsheet 專用訂閱表保存已驗證及退出紀錄，原洽詢主表不變。外部 API 憑證沿用 n8n Credentials，不隨 Pages 部署。信箱假名化 salt 是新資料表內的專用技術資料，不能替代或授權外部 API。

每封信先保存持久意向，建立草稿後保存 ImmutableId；寄送意向亦先保存，再交寄一次並讀回同一寄件備份。未知結果不建第二封、不清紀錄重送。已有草稿若需修復，須先核對同一 ImmutableId、收件人、主旨、本文及尚未交寄的意向，再採用原草稿；不能從「目前找不到」推論從未寄出。

寄件備份核對與 API 接受不等於實收。本輪自有公司信箱測試另核對了驗證及確認信的真實收件匣；詳細證據保留在專案內部，不放 Pages。

Smartsheet 先核對九欄、唯一訂閱識別碼與原列，再新增或更新；逐欄讀回成功後才記錄同步完成。退訂更新同一筆紀錄，並讓尚未寄出的舊代課程通知失效。已交寄的信無法撤回。驗收資料標記且排除未來課程廣播。

## 不受本功能改動的項目

原洽詢 v3、附件、公司通知與填表者收件確認信維持啟用。首頁、Sitemap 4.0、匿名案例、三篇文章初稿與 noindex、Podcasts 原週二排程不變。CMS、RAG、會員與英文版屬選配。

正式課程仍需先由公司核定並公告，才可由私有流程建立課程通知工作；本輪沒有建立虛構課程、公告排程或對舊洽詢者廣播。首次真實課程通知須在實際課程上架後驗收。
