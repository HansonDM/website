# 表單接收狀態恢復｜2026-10-24

沿用現有InquiryForm與五則收件說明，不改Sitemap、CSS、首頁或Banner。正式n8n v3、附件、公司與填表者確認信維持啟用；未改後端、憑證、郵件模板、Smartsheet欄位或政策版本。

## 接收能力與安全恢復

lib/intake-availability.ts只做公開GET：method GET、cache no-store、credentials omit，無表單、檔案、編號或私有資料。10秒逾時會中止請求並結束等待；遲到回覆不能恢復過時狀態。useIntakeAvailability在卸載／失效時中止並用世代旗標保護，檢查期間不開放提交；不自動輪詢。

首次檢查失敗、503 unavailable或notice_changed後，未收件表單可選「重新確認接收狀態」，或用既有公開信箱洽詢。不重新整理、不重建表單、不清未送出文字及附件；重查只有GET，不能重新POST。合作模式切換沿用同一form。received／pending回執不提供重查按鈕，維持原UUID、防重及禁止重送；本功能不查詢個人收件狀態或判定送達。

## 告知與附件

公開能力的告知版本改變時，取消原勾選並提示重新閱讀；未自行送出。附件能力若暫時不可用，仍保留FileList並在送出前明確擋下，不能因disabled欄位未進FormData而默默漏附件。新增「移除已選附件」只清本頁選擇，保留其他欄位，不刪已收件的私有檔案。

同意版本及能力仍由伺服器最後核對；頁面不是版本或權限繞過。待確認／未知狀態仍保留原收據，禁止盲重送；舊回執、填表者確認信資格布林與原公開說明連結保持。
