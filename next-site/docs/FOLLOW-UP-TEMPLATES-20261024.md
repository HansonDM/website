# 收件後聯絡與資料權利範本

本階段依網站盤點的收件後處理需求，先提供不需新增業務資料的公開聯絡範本；實際責任分工、處理時限、資料權利辦理與容量清理仍由公司決定及人工執行。

## 功能範圍

- `/contact/#follow-up-templates`：收件核對、補充與更正、資料權利三個空白範本；原有五則收件說明保留。
- `/privacy/#rights-help`：相同資料權利範本；公開信箱、保存原則及告知版本2026-10-24-v3不變，仍為noindex,nofollow。
- 每個範本可直接閱讀、開啟郵件草稿、複製或下載UTF-8文字檔。未啟用腳本仍可閱讀、開啟草稿與下載。
- 原生details及既有receipt-action／圓角／藍灰金色延續，不增加內容頁、路由、FAQ或Sitemap網址。公開搜尋只補強現有contact記錄，含案例仍103筆，知識FAQ仍18筆。

## 資料邊界

公開範本固定空白內容及Hanson.lin@hansondm.com，不讀表單欄位、附件、URL參數、sessionStorage或收據。所有範例空格均由訪客在自己的郵件中修改，不在網站新增個資輸入表單。

開啟草稿不會自動寄信。複製或下載不代表受理、收件、預約或完成更正／刪除。不新增自動追蹤、SLA或自動資料刪除，也不重新寄送歷史確認信。

複製需掛載完成；剪貼簿拒絕時提供唯讀選取備援。關閉範本、hash／歷史變更與卸載會使舊狀態回應失效；來源URL及文字一致才顯示完成訊息。這不宣稱能撤銷已發起的系統剪貼簿寫入。

文字下載由scripts/content-index.cjs從同一份lib/follow-up-templates.ts產生，只有公開靜態範本，不讀私人資料或外部來源。
